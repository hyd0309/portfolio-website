# Huangyd Portfolio

Personal website source for [huangyd.is-a.dev](https://huangyd.is-a.dev/).

## Structure

- `dist/` contains the static site files.
- `dist/monitor_cymatics/` contains the monitor_cymatics tool introduction page.
- `dist/downloads/` contains its supporting-file ZIP.
- `dist/ai/audio-archive/` is intentionally excluded from this repository. The public `/plugin-archive/` route is maintained by a separate service and is not deployed from this legacy local copy.
- `reference-assets/` contains the original design references used during development.
- `docs/` and `tests/` contain project notes and checks.

This repository is the source archive for the site. Publishing changes to this repository does not by itself configure or change the site's hosting provider.
